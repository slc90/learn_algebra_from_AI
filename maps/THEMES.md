# THEMES · 什么思想在不断生长

Stage 回答现在学什么，[ACTIONS](ACTIONS.md) 回答怎样操作，本页追踪思想的变化，[RESEARCH](RESEARCH.md) 展示远端问题。主题不是先修考试，也不记录掌握状态。沿当前 Stage 学习，遇到熟悉机制时再来比较它改变了哪些对象与假设。

<a id="t01"></a>
## T01 · 生成、关系与高阶关系

[整数线性组合 S002](../stages/S002.md) → [群的生成与关系 S013](../stages/S013.md) → [模的表示 S025](../stages/S025.md) → [关系矩阵 S027](../stages/S027.md) → [解消 S088](../stages/S088.md) → [Koszul S092](../stages/S092.md) → [导出交集 DA00](../research/DA00.md)。

一开始生成元告诉我们“能到达什么”；加入关系后，表达不唯一。关系自己也可能相关：在 k[x,y] 中 x、xy 的关系由 (−y,1) 生成，Koszul 边界却只有它的 x 倍，差额成为同调。继续重复“生成核”产生 free resolution。高阶关系不是额外考试，而是精确描述对象所不可避免的数据。

回访时问：当前展示的矩阵是在表示对象、表示关系，还是表示关系之间的关系？终止条件来自算法、正则序列，还是投射维数定理？

<a id="t02"></a>
## T02 · 商、映射与泛性质

[等价类 S004](../stages/S004.md) → [商群 S014](../stages/S014.md) → [商环 S020](../stages/S020.md) → [余核 S026](../stages/S026.md) → [泛性质 S030](../stages/S030.md) → [局部化 S039](../stages/S039.md) → [纤维积 S101](../stages/S101.md)。

共同问题是：哪些映射应该经新对象唯一分解？群商要求消去正规子群，环商要求消去理想，局部化要求指定元素可逆。它们都由映射刻画，但不是同一种运算。范畴中余等化子把“让两条箭头相同”抽象出来；更远处的 quotient stack 还保留点的自同构，derived quotient 还可能保留高阶关系。这些远端结构须补下降、群胚与同伦语言，不能把普通商集直接改名。

回访时问：唯一的是元素、兼容映射，还是仅到同构？如果忘掉自同构或同伦，会丢掉什么？远端见 [R4](RESEARCH.md#r4)、[R7](RESEARCH.md#r7)。

<a id="t03"></a>
## T03 · 正合、扩张与障碍

[核与纤维 S003](../stages/S003.md) → [短正合列 S026](../stages/S026.md) → [同调 S042](../stages/S042.md) → [Tor S089](../stages/S089.md) / [Ext S090](../stages/S090.md) → [导出范畴 S096](../stages/S096.md) → [形变 DD00](../research/DD00.md) / [高阶代数 HA00](../research/HA00.md)。

从 Z/4 不能拆成两个 Z/2 出发，Ext 把“不能拆”升级为连接方式的分类。张量丢失单射时，Tor 保存失效位置。节点 xy=0 的方向 (1,1) 在双数上合法，提升到三阶却留下 ε²；障碍不是答题错误，而是对象本身的结构。余切复形把导子与方程关系放在同一个复形中，进而通向 formal moduli 与 derived geometry。

回访时问：核像差额处于哪一个次数？扩张是否固定端点？当前算到的是障碍空间，还是某次提升的具体障碍类？

## T04 · 局部化、拼接与完备化

[允许分母 S039](../stages/S039.md) → [DVR S062](../stages/S062.md) → [完备化 S065](../stages/S065.md) → [素谱 S070](../stages/S070.md) → [层与茎 S098–S099](../stages/S098.md) → [概形 S100](../stages/S100.md) → [上同调 S108](../stages/S108.md)。

局部化忽略远处，完备化保存所有有限精度，层描述不同局部窗口如何相容。三者不可替代：Z_(p) 是有理数子环，Zₚ 是完备化，茎则通过缩小开邻域取极限。有限生成条件使“逐生成元清分母”成为有限乘积，也让 Artin–Rees 控制两种滤过。

继续前进有两条接口：[PA00](../research/PA00.md) 用 Frobenius 与根塔通向 perfectoid / prismatic；[CS00](../research/CS00.md) 用 profinite 测试空间与层条件通向 condensed / solid。回访时问：这里是哪种极限？是否需要完备？局部存在为什么未必能全局拼接？

<a id="t05"></a>
## T05 · 对称、表示与不变量

[可逆变换 S005](../stages/S005.md) → [群作用 S015](../stages/S015.md) → [表示 S033](../stages/S033.md) → [特征标 S044](../stages/S044.md) → [箭图 S049](../stages/S049.md) → [最高权 S057](../stages/S057.md) → [范畴化 CR00](../research/CR00.md)。

元素个数先成为不变量，再被阶、维数、迹、最高权改进。必须不断问“不变量是否完整”：复有限群半单表示可以由特征标恢复，非分裂箭图表示却不能由维数向量恢复。K₀ 把短正合列变成加法关系，方便计数也主动忘记扩张；[KT00](../research/KT00.md) 从投射模计数出发追问高 K 理论与 THH/TC。

远端的几何表示、cluster、稳定性与 Langlands 会汇合多个主题，见 [R5](RESEARCH.md#r5)、[R6](RESEARCH.md#r6)、[R8](RESEARCH.md#r8)、[R14](RESEARCH.md#r14)。它们不是单靠记住一个不变量就能进入的课程终点。

## T06 · 线性化、对偶与换底

[坐标 S007](../stages/S007.md) → [对偶 S024](../stages/S024.md) → [张量 S031](../stages/S031.md) → [外幂 S032](../stages/S032.md) → [Lie 括号 S052](../stages/S052.md) → [微分 S082](../stages/S082.md) → [族 S110](../stages/S110.md)。

对偶通过所有线性观察理解对象；张量把双输入线性化；微分保留方程的一阶变化。每一步都要注明底环：C⊗_R C 与 C⊗_C C 不同，特征 2 会改变交替与变号的关系，特征 p 的导数会让 Frobenius 不再被通常的分歧直觉解释。远端的余切复形把“一阶线性化”与“关系的高阶信息”合并，回到 [T03](#t03)。
