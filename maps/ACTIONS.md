## 三条纵向回访示例
施加关系：S004商集合 → S014商群 → S020商环 → S025模的表示 → S074理想规范化 → S096把拟同构变可逆。后一步不是前一步的同义词，必须说清失去了什么、增加了什么。
分解与连接：S009互素拆分 → S026分裂正合列 → S028算子循环部件 → S046不可分解 → S090扩张类 → S050箭图中的连接。
局部观察与拼接：S039局部化 → S062赋值 → S071局部生成 → S098层 → S099茎 → S108拼接障碍。

每次回访让学习者先说旧环境中的事实，再预测新环境中哪些仍真；用新反例决定边界。不要只展示两个相似公式就宣布完成迁移。

## 使用动作导航

面对新对象，先问由什么生成、关系是什么、有哪些自然映射、核与像记录什么。需要消去关系时看 M04，需要允许分母时看 M10；需要换底、对偶或保存正合失败时分别看 M09、M12、M13。

这些动作不形成第二套学习状态。日常沿当前 Stage 阅读，只在比较方法时回访本页。现代入口中，[DD00](../research/DD00.md) 继续线性化与障碍，[DA00](../research/DA00.md) 继续换底与正合，[KT00](../research/KT00.md) 继续不变量与稳定替代。
