# S097 · 同调综合：信息到底在哪一步丢了

## 这一阶段在研究什么

普通商或张量看起来很简单，高次信息却能区分不同相交方式。选择工具时要定位究竟哪一步失去正合性。

### 快速回顾与符号语言

需要 Tor、Ext、Koszul 与导出张量。固定 R=k[x,y]，M=R/(x)。利用解消 0→R —×x→R→M→0 比较不同第二因子。

## 先看几个具体例子

### 例 1 · 最简单模型

M⊗_R R/(y)=k，把两条坐标轴交在原点。

### 例 2 · 结构真正开始工作

M⊗_R M=M，普通自交仍是一条轴。

### 例 3 · 失败与边界

有限计算中未发现高次同调不意味着全部消失；双数环模型必须用周期性或一般定理证明无限非消失。

## 核心定理与证明机制

若 x 对 N 为非零因子，则 Tor₁^R(R/(x),N)=0；若 xN=0，则 Tor₁≅N。证明直接张量上述一步解消，所得一阶同调是乘 x 的核。

## 一个完整 Worked Example

取 N=R/(y)≅k[x]，乘 x 单射，故高次信息为零，H₀=k。改取 N=M≅k[y]，乘 x 为零，故 H₁=M、H₀=M。两种交都由同一自由解消计算，唯一变化是 x 对第二因子如何作用。这指出自交时方程已失去独立约束，Tor 把重复约束保存下来。

## 一个贯穿模型

比较R=k[x,y]上R/(x)的自张量与和R/(y)的张量：普通商环有时已经很简单，但导出信息仍区分相交方式。
